# 自然中文句法规范

本规范提炼自余光中《怎样改进英式中文？——论中文的常态与变态》，用于中文说明、翻译和工作写作。它关注的不是某个词能不能用，而是句子有没有因照搬英语结构而变得繁琐、生硬或含混。

目标是写出这样的中文：措辞简洁，动作清楚，句式灵活，读起来顺畅。

## 适用范围

本规范适用于：

- 中文工作材料、新闻、评论和一般说明文；
- 英译中，以及受英文材料影响较深的中文初稿；
- 对现有文本做句法审校和去翻译腔处理。

以下情况不宜机械套用：

- 法律条款、标准、学术定义需要保留固定术语或严密限定；
- 技术文档需要明确因果、条件和范围，不能只为简短而省略逻辑；
- 文学创作可以有意打破常规；
- 引文、合同原句和专有名称不得擅改。

## 判断标准

出现下列情况时，应当改写：

- 句子变长了，却没有增加信息；
- 原本明确的动作变成了抽象名词；
- 看不出谁做了什么，或谁承担责任；
- 修饰语过长，中心词迟迟不出现；
- 因果、转折、并列等关系重复标记或搭配错误；
- 句子语法成立，但正常说中文的人不会这样表达。

不要看到“的”“被”“关于”“之一”等词就直接删除。只有它们造成冗余、歧义或生硬时，才需要调整。

## 一、先写清谁做什么

中文通常更适合用人、事物或完整事件作主语，再让动词直接承担动作。不要把变化和动作一律抽象成名词。

| 生硬写法 | 推荐写法 |
| --- | --- |
| 用户数量的增长带来了服务器负载的上升。 | 用户增多后，服务器负载也上升了。 |
| 预算的削减导致了计划的调整。 | 预算减少后，我们调整了计划。 |
| 版本的发布需要产品负责人的批准。 | 发布版本前，须经产品负责人批准。 |

改写时先问：

1. 真正发生了什么？
2. 谁触发或完成了这个动作？
3. 读者是否需要知道责任人？

责任人未知、不重要或不便说明时，可以用事件作主语，不必硬补一个人。

## 二、让动词直接承担动作

警惕“宽泛动词＋动作名词”的结构，例如“进行分析”“开展讨论”“作出决定”“实施检查”“予以调整”。如果一个具体动词就能说清，优先直接使用。

| 生硬写法 | 推荐写法 |
| --- | --- |
| 团队对日志进行了分析。 | 团队分析了日志。 |
| 双方就交付日期开展了讨论。 | 双方讨论了交付日期。 |
| 负责人作出了暂停发布的决定。 | 负责人决定暂停发布。 |
| 运维对配置予以调整。 | 运维调整了配置。 |

这类结构并非一概错误。需要强调过程、制度动作或正式行为时，可以保留，例如“开展为期三个月的调查”“实施分级管理”。判断标准是：前面的动词是否提供了独立信息。

## 三、抽象词只保留必要的

“性、度、化、力、感、层面、维度、机制”等词可以准确命名概念，也容易把简单意思包装得过于学术。能用具体状态或动作说明时，不要绕进抽象名词再绕回来。

| 抽象写法 | 更具体的写法 |
| --- | --- |
| 这份说明具有较强的可读性。 | 这份说明容易读懂。 |
| 方案的可执行性不足。 | 方案没有写清负责人和完成时间。 |
| 需要提升系统的稳定性。 | 需要把每周故障次数降到两次以内。 |
| 从流程层面进行优化。 | 删除两个重复审批节点。 |

如果抽象词已有明确、稳定的专业含义，就应保留。“可用性”“一致性”“流动性”等术语不能为了口语化随意替换。真正的问题不是抽象，而是抽象词没有落到可观察的事实。

## 四、数量只标一次

中文名词通常不靠词尾表示复数。句中已有“所有、各、许多、三名、全体”等数量信息时，不再叠加“们”。

- `所有参会人员们`改为`所有参会人员`；
- `三位专家们`改为`三位专家`；
- `各部门负责人们`改为`各部门负责人`。

“人们”“朋友们”“同学们”已经是现代汉语的自然用法，不必禁用。只需避免重复标记数量。

“之一”只在集合范围确实重要时使用：

- 范围明确且需要定位成员时可以保留，如“七项原则之一”；
- 只是泛泛表示“还有别的”时，通常可以直说，如“这是主要风险”；
- “最重要的……之一”只有在确有一组并列的最高等级对象时才使用，否则改成“主要”“很重要”或给出明确排序。

## 五、关系词按真实关系使用

中文可以靠语序、停顿和上下文表示关系，不必给每组词都加“和、与、及、以及”。需要连接词时，应选能准确表达并列、递进、转折或因果的词。

### 并列

短而明确的并列项可以直接排列：

- `设计、研发以及测试共同参加评审`可改为`设计、研发、测试共同参加评审`；
- 两项内容容易误读为一个整体时，保留“和”或“与”。

### 转折与递进

不要用“及”代替所有关系：

- `成本更低及交付更快`应按原意改为`成本更低，交付也更快`；
- `速度慢及结果稳定`应改为`速度较慢，但结果稳定`。

### 因果

避免同一句重复叠加因果标记，也不要让介词结构悬空：

| 问题写法 | 推荐写法 |
| --- | --- |
| 由于网络抖动，使得请求中断。 | 网络抖动导致请求中断。 |
| 因为资源不足，因此项目延期。 | 因为资源不足，项目延期了。 |
| 基于这个原因，我们决定取消。 | 因此，我们决定取消。 |

因果是否可以省略，取决于读者会不会误解。技术说明、事故复盘和决策材料中的关键逻辑应明确写出，不能为了追求所谓“中文味”而省掉必要关系。

## 六、删除没有作用的介词框架

“关于、有关、对于、在……方面、在……情况下”常被用来搭一个空架子。删掉框架后意思不变，就让对象直接进入句子。

| 冗长写法 | 推荐写法 |
| --- | --- |
| 关于本次故障，我们进行了详细复盘。 | 我们详细复盘了本次故障。 |
| 对于延期问题，团队已经给出说明。 | 团队已经说明延期原因。 |
| 在成本控制方面，我们仍有改进空间。 | 我们仍需降低成本。 |
| 有关权限申请的流程，请参阅附件。 | 权限申请流程见附件。 |

介词承担范围限定或话题转换时可以保留。例如，一份文档同时讨论成本、工期和质量，“在成本方面”能够明确切换维度，就有实际作用。

## 七、副词必须增加信息

不要习惯性给动作加“成功地、有效地、积极地、充分地、切实地”等副词。动作或结果已经包含这层意思时，删掉；确实需要区分尝试与结果时，保留或改成具体结果。

| 空泛写法 | 推荐写法 |
| --- | --- |
| 团队成功地完成了数据迁移。 | 团队完成了数据迁移。 |
| 新流程有效地减少了等待时间。 | 新流程把平均等待时间从 20 分钟降到 8 分钟。 |
| 各部门积极地配合了检查。 | 各部门按时提交了检查材料。 |

如果“成功”本身就是需要报告的结果，例如此前多次失败，则不能直接删除。可以写成：“第三次迁移成功，数据校验无误。”

较长的成语、短语或分句，不要硬加“地”压成副词。可以改成独立分句：

- `团队在时间不足的情况下争分夺秒地完成了修复`可改为`时间紧，团队赶在截止前完成了修复`。

## 八、少让“的”承担全部关系

“的”是正常且必要的结构助词，问题在于连续使用后容易造成节奏拖沓和修饰关系不清。

出现两个以上“的”时，检查能否：

- 删去不影响含义的“的”；
- 把动作恢复成动词；
- 用“而、并、但”等词说明关系；
- 把长修饰语拆成后续分句；
- 调整词序，让修饰语贴近所修饰的对象。

| 拖沓写法 | 推荐写法 |
| --- | --- |
| 客户的退款申请的处理进度 | 客户退款申请的处理进度 |
| 系统的自动的恢复能力 | 系统自动恢复的能力 |
| 灰暗的拥挤的没有窗户的会议室 | 会议室灰暗、拥挤，也没有窗户 |

不要追求完全不用“的”。删去后如果改变限定范围、造成歧义或不合习惯，就应保留。

## 九、长修饰语移到中心词后面

中文可以前置修饰语，但前置部分太长时，读者必须记住大量信息，直到句尾才知道中心对象。中心词应尽早出现，较长说明放到后面。

| 头重脚轻 | 推荐写法 |
| --- | --- |
| 我们上线了一个经过三轮评审并由法务确认符合当地规定的新流程。 | 我们上线了一套新流程。这套流程经过三轮评审，法务也确认它符合当地规定。 |
| 这是一个能够自动发现异常并在五分钟内通知负责人的监控工具。 | 这个监控工具能自动发现异常，并在五分钟内通知负责人。 |

前置修饰语短、稳定且不会误读时，可以保留，如“本周新增的三个问题”。不需要为了拆句而拆句。

## 十、主动句优先，但不排斥被动句

动作发出者已知且重要时，主动句通常更短，也更容易看清责任。

| 被动写法 | 推荐写法 |
| --- | --- |
| 这个决定不被多数成员接受。 | 多数成员不接受这个决定。 |
| 三处错误被测试人员发现。 | 测试人员发现了三处错误。 |
| 申请没有被批准。 | 申请未获批准。 |

以下情况可以使用被动句：

- 受影响对象才是当前话题；
- 动作发出者未知、不重要或不宜说明；
- 需要强调遭受的影响；
- 专业文体已有稳定用法。

即使需要被动含义，也不必只用“被”。“获准、受损、遇阻、遭拒、为……所……”等表达各有语气，应按事实选择，不能为了变化而堆砌。

## 十一、成语和现成说法重在准确

熟悉中文已有的短语和句式，有助于避免把简单意思绕成长句。成语可以凝练表达，也可能显得陈旧、夸张或含义含混。

- 读者熟悉、含义准确、比解释更简洁时，可以使用；
- 只为显得有文采，或会遮住事实时，不用；
- 专业材料中，具体数字和动作优先于成语评价。

例如，与其写“不是一句话就能够说清楚”，可以视语境写“一言难尽”；但事故说明不能用“一波三折”代替具体经过。

## 十二、不要机械反西化

语言会吸收新的词义和句式。判断一种表达是否值得保留，不看它是不是外来的，而看它是否已经自然、准确、有效。

以下理由足以保留看似“西化”的表达：

- 它已经成为现代汉语的稳定用法；
- 它比传统说法更准确地表达新概念；
- 它能消除责任、范围、条件或逻辑上的歧义；
- 行业、法律或技术语境要求这样写；
- 改写后反而更长、更别扭或改变原意。

规范的目标是消除机械模仿，不是把现代中文写成仿古文。

## 翻译和改写步骤

1. **提取事实。** 暂时放下原句词序，写出人物、动作、对象、时间、条件和结果。
2. **找到句子主干。** 先写“谁做什么”或“什么发生了什么变化”。
3. **恢复具体动词。** 检查“进行、开展、作出、实施”等词后面是否藏着真正的动作。
4. **拆开名词链。** 把抽象名词还原成动作或状态，把长前置修饰语移到中心词后面。
5. **整理逻辑。** 每层因果、转折或并列只用必要的标记，关键关系不能省。
6. **删除冗余。** 重点检查空介词、重复数量、无信息副词和连续的“的”。
7. **核对原意。** 确认事实、范围、语气和承诺强度没有改变。
8. **朗读全文。** 如果读到句尾才明白主语，或一句话中途需要回看，就重组句子。

## 快速审校清单

- [ ] 读者能否迅速看出谁做什么、发生了什么？
- [ ] “进行、开展、作出、实施、予以”能否换成一个准确动词？
- [ ] 抽象词是否落到了事实、动作或指标上？
- [ ] 数量是否被“所有／各／数字”和“们”重复标记？
- [ ] “之一”是否真的需要交代集合关系？
- [ ] “关于、对于、在……方面”删掉后，意思是否不变？
- [ ] 因果、并列和转折是否重复标记或使用错了连接词？
- [ ] “成功地、有效地、积极地”等副词是否提供了新信息？
- [ ] 连续的“的”是否造成歧义或拖慢句子？
- [ ] 中心词是否被过长的前置修饰语压到句尾？
- [ ] 被动句是否有保留的理由？
- [ ] 改写后是否仍然准确，且比原句更自然、更容易理解？

## 来源与取舍

思想来源：余光中《[怎样改进英式中文？——论中文的常态与变态](https://language.chinadaily.com.cn/2015-09/01/content_21765083.htm)》，原载《明报月刊》1987年10月号。

本规范不是原文摘录，而是面向现代中文写作的重述。原文对“人们”“之一”“被”等表达的批评较为绝对；本规范将它们改成按语境判断的预警项，避免把语言观察变成词语禁令。
