# ai-detox 评测集 v1

可回归的检测测试集。用于验证 skill 的检出率 / 误报率。

- 正例 = 应命中 ≥1 处,expected 列给出应命中的类别与词
- 负例 = 应零命中(测误报率)
- **语境负例 = 词在词表中出现,但语义有实指 → 应零命中**(测试语境判定,最关键的误报防线)
- **🟤 结构层用例 = 词表零命中但行文思路有 AI 味的整段用例**(S1-S4 宏观诊断,见下)
- **⚫ 标点级用例 = 标点/排版信号专项评测**(B1-B4 正例 / B-N1~B-N4 负例;判定口径:只看 ⚫)
- **🟢(M) 修饰膨胀用例 = 多类空泛修饰词堆叠专项**(M1-M2 正例 / M-N1~M-N2 负例;判定口径:只看 🟢(M))
- 判定口径:命中 = 类别命中计数正确;误报 = 负例/语境负例命中 ≥1
- 验收线(2026-08-29 已拍板):正例 ≥9/10(E7 hard 例外不列入),负例误报 0/5,语境负例误报 0/8
