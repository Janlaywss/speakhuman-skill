# ai-detox — AI 味中文写作检测 Skill

一键检测文本中的"AI 味"特征，覆盖 8 类常见病态模式。

## 用法

```bash
python3 bin/detect.py "你的文本"
# 或从文件读取
python3 bin/detect.py < input.txt
```

## 检测类别

| 类别 | 符号 | 说明 |
|------|------|------|
| 借喻黑洞词 | 🔴 | 抽象隐喻替代具体动词（赋能、抓手、打通、闭环…） |
| 元话语 | 🟠 | 无主体万金油（我们可以看到、值得注意的是） |
| 万能修辞 | 🟡 | 空洞铺垫（在当今…背景下、随着…发展） |
| 结构癖 | 🟢 | 三连排比/虚化修饰/后缀病等 5 种句型病 |
| 修饰膨胀 | 🟢(M) | ≥2 类空泛修饰词堆叠无数字支撑 |
| 占位语气 | 🔵 | 合规腔/不确定表述（以…为准、暂定、可灵活调整） |
| 标点级 | ⚫ | 破折号滥用/半角标点/引号抽象词/满屏加粗 |
| 行文结构病 | 🟤 | S1-S5c：时代开篇、目标空洞、价值虚化、空总结段等宏观病 |

## 验收线

- 正例 ≥9/10（E7 hard 例外不列入）
- 负例误报 0/5
- 语境负例误报 0/8

当前版本：**v1.7.3**，回归 **33/33** 全过。
